OASISだけの特徴

単なる診断テストではない。会話するたびに進化する、あなた専用のAI。

✦

会話型パーソナリティ分析

質問に答えるだけじゃない。日常の会話からAIが自然にあなたの5軸スコアを分析します。

🌐

共鳴スコアで相性発見

友人・恋愛・仕事の3カテゴリで他ユーザーとの相性をスコア化。本当に合う人を見つけられます。

🪞

デジタル分身

あなたのAIが他のユーザーからの質問に答えます。在籍していなくても、あなたらしさが伝わります。

🔒

プライバシー最優先

AIとの会話内容は他のユーザーに公開されません。分析結果のスコアのみが共有されます。

🌙

ダークモード対応

目に優しいダークテーマと、清潔感のあるライトテーマを切り替えて使えます。

🌐

日本語・English対応

日本語と英語に対応。設定からいつでも切り替えられます。

3ステップで始める

難しい設定は一切不要。ダウンロードしてすぐ使えます。

1

AIと話す

日常のことを気軽に話しかけるだけ。テストや質問票への回答は不要です。

2

性格が分析される

10回の会話でパーソナリティ分析が始まります。話すほど精度が上がります。

3

相性の合う人と繋がる

共鳴タブで相性スコアが高いユーザーを発見。フレンド申請してDMを送れます。
